FORDY FLOW / iPHONE + APPLE WATCH

语音键盘与会议录音转写

说话即可输入，让对话成为记录。跟随你的语言使用语音键盘和会议、访谈录音。

iOS 18+ · Voice Input iOS 26+
01

语音键盘

在其他应用中语音输入，也可使用内置键盘打字。

02

录音

录制会议和访谈，或导入音频、视频进行转写。

03

编辑录音

区分说话人，检查并编辑转写内容和会议纪要。

自行选择处理方式。本地模式在设备上处理；Groq 模式使用你自己的 API 密钥，将音频、转写及处理所需的信息直接发送至 Groq。原始会议录音保存在设备上。

支持简体中文、韩语、英语、日语、西班牙语、德语和法语。默认跟随设备语言，也可在应用设置中更改。语音识别语言单独选择。

基本功能需要 iOS 18 或更高版本，语音键盘需要 iOS 26 或更高版本。Apple Intelligence 功能需要受支持的设备、语言及已就绪的系统模型。本地模型需单独下载。Groq 需要你自己的账户和 API 密钥，并适用其费用及用量限制。

首个版本免费。录音前请取得参与者同意并遵守组织政策。
