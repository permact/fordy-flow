FORDY FLOW / PRIVACY

隐私政策

生效日期：2026 年 11 月 5 日
运营者：Kim BJ
联系方式：ujbj84@gmail.com

1. 基本原则

Fordy Flow 提供语音键盘、会议与访谈录音、转写及会议纪要功能。Fordy 不运营自有服务器或用户账户服务。本地处理模式在设备上处理录音和文本。只有当你连接自己的 API 密钥并选择 Groq 处理方式时，才会使用 Groq。

2. 设备上保存的信息

原始录音、转写、说话人姓名、会议纪要、文件夹、标签、用户词典及应用设置均保存在应用的设备存储中。语音键盘的命令和临时结果仅通过同一 App Group 在应用及键盘扩展之间共享。Groq API 密钥保存在此 iPhone 的钥匙串中，不包含在键盘扩展、普通设置文件或诊断报告中。

3. 可选 Groq 处理及跨境处理

选择 Groq 时，音频会发送至 api.groq.com 的语音识别 API。转写、说话人姓名、会议输入，以及文本整理所需的用户指令、目标应用信息和词典提示，仅在相关请求所需的范围内发送至 Groq API。API 密钥用于验证你的 Groq 账户，请求不经过 Fordy 中转服务器。
Groq Inc. 会保留服务使用元数据。Groq 表示，默认不保留输入和输出，但为系统可靠性检查、滥用调查等目的，可能保留最多 30 天，或保留法律要求的期限。保留的客户数据存储在美国。实际保留政策取决于你的 Groq 账户及 Data Controls 设置。Groq 的 Zero Data Retention 设置由你在 Groq 管理；Fordy 不会代为启用，也不保证所有账户均不保留数据。
数据政策：https://console.groq.com/docs/your-data
隐私政策：https://groq.com/privacy-policy/
你可以切换到本地模式，并在设置中删除 API 密钥，以停止今后的 Groq 请求。已发送至 Groq 的信息相关请求按该服务的政策处理。

4. 模型下载和 Apple 功能

准备本地语音识别及说话人区分模型时，模型会从 Apple 的模型或资源分发服务，或 Hugging Face 模型仓库下载。IP 地址等网络请求信息可能传递给这些提供商。下载模型不会将录音或转写上传至模型仓库。Apple 语音识别及 Apple Intelligence 是否可用，取决于设备、系统版本、语言及系统模型准备状态。

5. 键盘的完全访问

键盘使用完全访问权限与 Fordy 应用共享录音命令和转写结果。输入内容不会用于广告、跟踪或数据销售。普通文字输入无需 Groq API 密钥或云端处理。iOS 安全输入框及其他受限场景可能使用系统键盘。

6. 可选搜索和诊断

开启系统搜索时，录音标题、创建时间和时长会注册到设备的 Core Spotlight。音频和转写正文不会加入搜索索引。
可选诊断在设备端保存系统及应用版本、录音时长类别、引擎、处理类型和成功、失败或取消状态。不包含音频、转写正文、标题、说话人姓名、文件夹名称、词典词条或 API 密钥，也不会自动发送。主动选择分享报告时，会发送给你选择的接收方。通过电子邮件联系支持时，你提供的邮箱地址、咨询内容及附件仅用于回复和解决问题。

7. 保留和删除

录音会保留到你将其删除为止。已删除的录音可在所选“最近删除”保留期（7、30 或 90 天）后移除，也可由你永久删除。语音输入临时数据在处理完成后清理。为便于重试，普通失败数据最多保留 10 分钟；等待 Groq 请求限额的数据可保留至限额重置后 10 分钟。关闭可选诊断后可删除相关本地记录。删除模型不会删除原始录音。
iPhone 与 Watch 的传输和备份可能受到设备及 Apple 备份设置影响。导出或保存到其他应用或云端的副本需在相应位置另行管理。

8. 广告、跟踪及信息销售

应用不使用广告或行为跟踪 SDK，也不销售个人信息。你选择的外部处理、下载及分享服务受各自政策约束。

9. 你的选择及联系方式

你可以在应用中更改处理方式、删除录音、记录、模型和 API 密钥，并关闭搜索或诊断。如需查询、更正、删除个人信息或咨询处理事项，请联系 ujbj84@gmail.com。Fordy 无法远程访问仅存储在设备上的录音或密钥。

10. 变更通知

功能或处理方式变化时，我们会更新本政策及生效日期。重要的外部传输变更也会在应用内说明。
