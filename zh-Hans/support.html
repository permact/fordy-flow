FORDY FLOW / SUPPORT

支持

ujbj84@gmail.com

请提供 iPhone 型号、iOS 版本、应用版本及重现步骤。请勿发送 API 密钥或密码。

应用语言

应用默认跟随设备语言，可在“设置 > 应用语言”更改。语音识别语言需单独选择。

如何添加键盘

  1. 打开“设置 → 通用 → 键盘 → 键盘”
  2. 点击“添加新键盘”→ 选择 Fordy Flow Keyboard
  3. Fordy Flow Keyboard → 开启“允许完全访问”

完全访问用于与应用共享临时结果，不收集其他应用中光标附近的文字。

Groq 连接

音频和转写内容会发送至 Groq。

基本功能需要 iOS 18 或更高版本，语音键盘需要 iOS 26 或更高版本。Apple Intelligence 功能需要受支持的设备、语言及已就绪的系统模型。本地模型需单独下载。Groq 需要你自己的账户和 API 密钥，并适用其费用及用量限制。

恢复中心

请在恢复中心查找中断的录音，并使用原始文件重试。解决录音问题前请勿删除应用。
