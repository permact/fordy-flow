iPhone 모델, iOS 버전, Fordy Flow 앱 버전과 문제가 발생한 순서를 알려주세요. API 키와 비밀번호는 보내지 마세요. 녹음·전사문 등 민감한 내용은 문의에 꼭 필요한 경우에만 직접 확인한 뒤 첨부해주세요.

처음 시작하려면 무엇이 필요한가요?

앱을 열고 초기 설정과 마이크 권한을 완료하세요. 로컬 전사에는 필요한 모델을 다운로드하거나 Apple의 지원 모델을 준비합니다. Groq 방식은 본인의 Groq API 키를 연결해 사용합니다. 녹음 전에는 참여자의 동의와 소속 조직의 정책을 확인해주세요.

키보드는 어떻게 추가하나요?

iPhone 설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가에서 Fordy Flow Keyboard를 선택하세요. 음성 입력에는 해당 키보드의 전체 접근 허용과 Fordy Flow 앱의 마이크 권한이 필요합니다. 일반 문자 입력은 Groq API 키 없이 사용할 수 있습니다.

어떤 iPhone에서 음성 입력을 쓸 수 있나요?

음성 키보드는 iOS 26 이상이 필요합니다. Apple Intelligence 방식은 해당 기능을 지원하는 기기·언어와 준비된 시스템 모델이 필요합니다. 지원하지 않는 기기에서는 본인의 API 키로 Groq 방식을 선택할 수 있습니다. 회의 녹음 등 기본 기능은 iOS 18 이상에서 사용할 수 있습니다.

앱은 무료인가요?

첫 버전은 무료로 제공할 예정입니다. Groq를 사용할 때는 사용자의 Groq 계정 요금·사용 한도가 별도로 적용됩니다. 앱 무료 제공이 외부 AI 서비스의 이용료를 포함하는 것은 아닙니다.

녹음이나 전사가 실패하면 어떻게 하나요?

앱의 복구 센터를 확인하세요. 원본 녹음은 AI 처리와 별도로 보관하므로 전사를 다시 시도할 수 있습니다. 문제 해결 전 앱을 삭제하지 마세요. 저장 공간과 전원 상태, 선택한 모델·API 연결 상태도 확인해주세요.

녹음과 API 키를 지우고 싶어요.

녹음은 최근 삭제함에서 영구 삭제할 수 있습니다. API 키는 설정 → Groq 연결에서 삭제하세요. 로컬 모델은 설정 → 로컬 모델에서 별도로 삭제할 수 있습니다. 공유·내보내기·백업한 복사본은 해당 저장 위치에서 별도로 관리해주세요.

내 녹음은 어디로 전송되나요?

로컬 모드의 콘텐츠는 기기에서 처리합니다. Groq 모드를 선택하면 음성·전사문 등 처리에 필요한 정보를 Groq에 직접 전송합니다. 자세한 내용과 보관 정책은 개인정보 처리방침을 확인해주세요.
