앱 언어

기기 언어가 기본값입니다. 설정 > 앱 언어에서 변경할 수 있습니다. 음성 인식 언어는 따로 선택합니다.

키보드 추가 방법

  1. 설정 → 일반 → 키보드 → 키보드 열기
  2. 새로운 키보드 추가 → Fordy Flow Keyboard 선택
  3. Fordy Flow Keyboard → 전체 접근 허용 켜기

전체 접근은 앱과 임시 결과를 공유할 때 사용합니다. 다른 앱의 주변 문장은 수집하지 않습니다.

Groq 연결

음성과 전사문을 Groq로 전송합니다.

기본 기능은 iOS 18 이상, 음성 키보드는 iOS 26 이상에서 사용할 수 있습니다. Apple Intelligence 기능에는 지원 기기·언어와 준비된 시스템 모델이 필요합니다. 로컬 모델은 별도로 다운로드합니다. Groq에는 본인 계정·API 키와 해당 서비스의 요금·사용 한도가 적용됩니다.

복구 센터

복구 센터에서 중단된 녹음을 확인하고 원본으로 다시 처리하세요. 문제 해결 전 앱을 삭제하지 마세요.
