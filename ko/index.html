말로 입력하고, 대화를 기록하세요. 기기 언어에 맞춰 쓰는 음성 키보드와 회의·인터뷰 기록.

01

음성 키보드

다른 앱에서 음성으로 문장을 입력하고, 직접 입력 키보드도 사용하세요.

02

녹음

회의·인터뷰를 녹음하거나 오디오·비디오 파일을 가져와 전사하세요.

03

기록 편집

화자를 구분하고 전사·회의록을 검토·편집하세요.

처리 방식은 직접 선택합니다. 로컬 모드는 기기 안에서 처리하고, Groq 모드는 본인의 API 키로 음성·전사문 등 필요한 정보를 Groq에 직접 전송합니다. 원본 회의 녹음은 기기에 보관합니다.

앱은 한국어, 영어, 중국어 간체, 일본어, 스페인어, 독일어, 프랑스어를 지원합니다. 기본 기기 언어를 따르며 앱 설정에서 바꿀 수 있습니다. 음성 인식 언어는 별도로 선택합니다.

기본 기능은 iOS 18 이상, 음성 키보드는 iOS 26 이상에서 사용할 수 있습니다. Apple Intelligence 기능에는 지원 기기·언어와 준비된 시스템 모델이 필요합니다. 로컬 모델은 별도로 다운로드합니다. Groq에는 본인 계정·API 키와 해당 서비스의 요금·사용 한도가 적용됩니다.

첫 버전은 무료입니다. 녹음 전 참여자의 동의와 조직 정책을 확인해주세요.
