FORDY FLOW / PRIVACY

개인정보 처리방침

시행일: 2026년 11월 5일
운영자: Kim BJ
문의: ujbj84@gmail.com

1. 기본 원칙

Fordy Flow는 음성 키보드, 회의·인터뷰 녹음, 전사와 회의록 기능을 제공합니다. Fordy 자체 서버나 회원 계정을 운영하지 않으며, 로컬 처리 모드에서는 녹음과 텍스트를 기기 안에서 처리합니다. Groq 모드는 사용자가 본인의 API 키를 연결하고 해당 처리 방식을 선택한 경우에 사용합니다.

2. 기기에 저장되는 정보

원본 녹음, 전사, 화자 이름, 회의록, 폴더·태그, 사용자 사전과 앱 설정은 앱의 기기 저장소에 보관합니다. 음성 키보드의 명령과 임시 결과는 본체와 키보드 확장 사이에서 같은 App Group으로만 공유합니다. Groq API 키는 이 iPhone의 Keychain에 저장하며 키보드 확장, 일반 설정 파일과 진단 보고서에 포함하지 않습니다.

3. 선택적 Groq 처리와 국외 처리

Groq 모드를 선택하면 음성을 api.groq.com의 음성 인식 API로, 전사문·화자 이름·회의 입력 내용과 문장 정리에 필요한 사용자 지침·대상 앱 정보·사용자 사전 힌트를 해당 요청에 필요한 범위에서 Groq API로 전송합니다. API 키는 사용자의 Groq 계정 인증에 사용됩니다. Fordy 중계 서버를 거치지 않습니다.
Groq Inc.는 서비스 이용 메타데이터를 보관하며, 입력·출력은 기본적으로 보관하지 않지만 시스템 안정성 확인·오남용 조사 등의 경우 최대 30일 또는 법률상 필요한 기간 동안 보관할 수 있다고 안내합니다. 보관되는 고객 데이터의 저장 위치는 미국입니다. 실제 보관 정책은 사용자의 Groq 계정과 Data Controls 설정에 따릅니다. Groq의 Zero Data Retention 설정은 사용자가 Groq에서 관리할 수 있으며, Fordy가 대신 적용하거나 모든 계정의 무보관을 보장하지 않습니다.
정책: https://console.groq.com/docs/your-data
개인정보처리방침: https://groq.com/privacy-policy/
사용자는 로컬 모드로 전환하고 설정에서 API 키를 삭제해 이후 Groq 요청을 중단할 수 있습니다. 이미 Groq로 전송된 정보에 관한 요청은 해당 서비스의 정책에 따라 처리됩니다.

4. 모델 다운로드와 Apple 기능

로컬 음성 인식·화자 분리 모델은 사용자가 준비할 때 Apple의 모델·자산 배포 서비스 또는 Hugging Face의 모델 저장소에서 다운로드됩니다. 이 과정에서 IP 주소 등 네트워크 요청 정보가 제공자에게 전달될 수 있습니다. 모델 다운로드를 위해 녹음이나 전사문을 모델 저장소로 업로드하지 않습니다. Apple 음성 인식과 Apple Intelligence 기능은 지원 기기·OS·언어와 시스템 모델 준비 상태에 따라 사용할 수 있습니다.

5. 키보드의 전체 접근

키보드의 전체 접근은 Fordy 본체와 녹음 명령·전사 결과를 공유하는 데 사용합니다. 입력 내용을 광고, 추적 또는 데이터 판매에 사용하지 않습니다. 일반 문자 입력에는 Groq API 키나 클라우드 처리가 필요하지 않습니다. iOS 보안 입력창 등에서는 시스템 키보드가 사용될 수 있습니다.

6. 선택형 검색과 진단

시스템 검색을 켠 경우 기록 제목·작성 시간·길이를 기기의 Core Spotlight에 등록합니다. 오디오와 전사 본문은 검색 인덱스에 넣지 않습니다.
선택형 진단에는 OS·앱 버전, 녹음 길이 범주, 엔진, 처리 종류와 성공·실패·취소 상태를 기기에 저장합니다. 녹음·전사 본문·제목·화자 이름·폴더명·사전 단어·API 키는 진단에 포함하지 않으며 자동 전송하지 않습니다. 사용자가 직접 보고서 공유를 선택하면 선택한 수신자에게 전달됩니다. 이메일로 문의하면 사용자가 제공한 이메일 주소·문의 내용·첨부 자료를 답변과 문제 해결에 사용합니다.

7. 보관과 삭제

녹음은 사용자가 삭제할 때까지 보관하며, 삭제한 기록은 설정한 최근 삭제함 보존 기간(7·30·90일) 후 제거하거나 사용자가 영구 삭제할 수 있습니다. 음성 입력 임시 자료는 작업 완료 시 정리하며 일반 실패는 최대 10분, Groq 호출 한도 대기는 한도 초기화 시점 후 10분까지 재시도를 위해 보관할 수 있습니다. 선택형 진단을 끄면 해당 로컬 기록을 삭제할 수 있습니다. 모델을 삭제해도 원본 녹음은 삭제하지 않습니다.
iPhone·Watch의 전송 및 백업 여부는 사용자의 기기·Apple 백업 설정에 영향을 받을 수 있습니다. 사용자가 내보내거나 다른 앱·클라우드에 저장한 복사본은 해당 위치에서 별도로 관리해야 합니다.

8. 광고·추적과 정보 판매

앱에 광고·행동 추적 SDK를 사용하지 않으며 개인정보를 판매하지 않습니다. 사용자가 선택한 외부 처리·다운로드·공유 서비스는 각 서비스의 정책을 따릅니다.

9. 이용자의 선택과 연락처

사용자는 앱에서 처리 방식을 변경하고, 녹음·기록·모델·API 키를 삭제하고, 검색·진단 기능을 끌 수 있습니다. 개인정보 열람·정정·삭제 또는 처리에 관한 문의는 ujbj84@gmail.com으로 보내주세요. Fordy는 기기에만 저장된 녹음이나 키에 원격으로 접근할 수 없습니다.

10. 변경 안내

기능이나 처리 방식이 변경되면 처리방침과 시행일을 갱신합니다. 중요한 외부 전송 변경은 앱에서도 안내합니다.
