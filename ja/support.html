FORDY FLOW / SUPPORT

サポート

ujbj84@gmail.com

iPhone 機種、iOS・アプリのバージョン、再現手順をお知らせください。API キーやパスワードは送らないでください。

アプリの言語

デバイスの言語が既定です。「設定 > アプリの言語」で変更できます。音声認識の言語は別途選択します。

キーボードの追加方法

  1. 「設定 → 一般 → キーボード → キーボード」を開く
  2. 「新しいキーボードを追加」→ Fordy Flow Keyboard を選択
  3. Fordy Flow Keyboard →「フルアクセスを許可」をオン

フルアクセスはアプリとの一時結果共有に使います。他のアプリのカーソル周辺の文章は収集しません。

Groq 接続

音声と文字起こしを Groq に送信します。

基本機能は iOS 18 以降、音声キーボードは iOS 26 以降が必要です。Apple Intelligence は対応デバイス・言語と準備済みのシステムモデルが必要です。ローカルモデルは別途ダウンロードします。Groq はご自身のアカウントと API キーが必要で、同サービスの料金・利用上限が適用されます。

復元センター

復元センターで中断した録音を探し、元データから再処理してください。録音の問題が解決する前にアプリを削除しないでください。
