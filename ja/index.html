FORDY FLOW / iPHONE + APPLE WATCH

音声キーボード・録音・文字起こし

話して入力、会話を記録に。あなたの言語で使える音声キーボードと会議・インタビュー録音。

iOS 18+ · Voice Input iOS 26+
01

音声キーボード

ほかのアプリに音声で入力し、内蔵キーボードで直接入力もできます。

02

録音

会議やインタビューを録音し、音声・動画ファイルからも文字起こしできます。

03

録音を編集

話者を分離し、文字起こしや議事録を確認・編集できます。

処理方法は選択できます。ローカルモードはデバイス内で処理し、Groq モードはご自身の API キーで音声・文字起こしなど必要な情報を Groq に直接送信します。元の会議録音はデバイスに保持します。

日本語、韓国語、英語、中国語（簡体字）、スペイン語、ドイツ語、フランス語に対応。デバイスの言語に従い、アプリ設定でも変更できます。音声認識の言語は別途選択します。

基本機能は iOS 18 以降、音声キーボードは iOS 26 以降が必要です。Apple Intelligence は対応デバイス・言語と準備済みのシステムモデルが必要です。ローカルモデルは別途ダウンロードします。Groq はご自身のアカウントと API キーが必要で、同サービスの料金・利用上限が適用されます。

初版は無料です。録音前に参加者の同意と組織の規定を確認してください。
