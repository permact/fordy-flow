FORDY FLOW / PRIVACY

プライバシーポリシー

施行日：2026年11月5日
運営者：Kim BJ
お問い合わせ：ujbj84@gmail.com

1. 基本方針

Fordy Flow は音声キーボード、会議・インタビューの録音、文字起こし、議事録の機能を提供します。Fordy 独自のサーバーやユーザーアカウントサービスは運営していません。ローカルモードでは録音とテキストをデバイス内で処理します。Groq は、ご自身の API キーを接続し、その処理方法を選んだ場合にのみ使用します。

2. デバイスに保存する情報

元の録音、文字起こし、話者名、議事録、フォルダ、タグ、ユーザー辞書、アプリ設定はアプリのデバイスストレージに保存します。音声キーボードのコマンドと一時結果は、同じ App Group を使ってアプリ本体とキーボード拡張の間だけで共有します。Groq API キーはこの iPhone のキーチェーンに保存し、キーボード拡張、通常の設定ファイル、診断レポートには含めません。

3. 任意の Groq 処理と国外での処理

Groq を選ぶと、音声を api.groq.com の音声認識 API に送信します。文字起こし、話者名、会議入力と、文章整理に必要なユーザー指示・対象アプリ情報・辞書ヒントは、各リクエストに必要な範囲だけ Groq API に送信します。API キーはご自身の Groq アカウントの認証に使用します。Fordy の中継サーバーは経由しません。
Groq Inc. はサービス利用のメタデータを保持します。Groq によると、入力と出力は既定では保持しませんが、システムの信頼性確認、不正利用の調査などのため最大30日、または法令で必要な期間保持する場合があります。保持される顧客データは米国に保存されます。実際の保持は Groq アカウントと Data Controls の設定に従います。Groq の Zero Data Retention はご自身で Groq 上で管理します。Fordy が代わりに有効化したり、全アカウントで非保持を保証したりすることはありません。
データポリシー：https://console.groq.com/docs/your-data
プライバシーポリシー：https://groq.com/privacy-policy/
ローカルモードに切り替え、設定で API キーを削除すると、以後の Groq リクエストを止められます。送信済み情報に関する依頼は、同サービスの方針に従って扱われます。

4. モデルのダウンロードと Apple の機能

ローカル音声認識・話者分離モデルは、準備時に Apple のモデル・アセット配信サービス、または Hugging Face のモデルリポジトリからダウンロードします。この際、IP アドレスなどのネットワークリクエスト情報が提供元に伝わる場合があります。モデルを取得するために録音や文字起こしをリポジトリにアップロードすることはありません。Apple 音声認識と Apple Intelligence は、対応デバイス、OS、言語、システムモデルの準備状況により利用できます。

5. キーボードのフルアクセス

フルアクセスは、録音コマンドと文字起こし結果を Fordy 本体と共有するために使用します。入力内容を広告、追跡、データ販売には利用しません。通常の文字入力に Groq API キーやクラウド処理は不要です。iOS の安全な入力欄などではシステムキーボードが使われる場合があります。

6. 任意の検索と診断

システム検索をオンにした場合、録音タイトル・作成日時・長さをデバイスの Core Spotlight に登録します。音声と文字起こし本文は検索インデックスに登録しません。
任意の診断では、OS・アプリのバージョン、録音時間区分、エンジン、処理の種類、成功・失敗・キャンセルの状態をデバイスに保存します。音声、文字起こし本文、タイトル、話者名、フォルダ名、辞書の単語、API キーは含めず、自動送信もしません。レポート共有を選んだ場合、選択した宛先に送られます。メールでのお問い合わせでは、提供されたメールアドレス・問い合わせ内容・添付資料を回答と問題解決に使用します。

7. 保存と削除

録音は削除するまで保持します。削除した録音は「最近削除した項目」の設定期間（7・30・90日）後に消去するか、ご自身で完全に削除できます。音声入力の一時データは処理完了時に整理します。再試行のため、通常の失敗は最大10分、Groq の上限待ちは上限リセット後10分まで保持する場合があります。任意の診断をオフにすると、該当のローカル記録を削除できます。モデルを削除しても元の録音は削除しません。
iPhone・Watch の転送やバックアップは、デバイスと Apple のバックアップ設定の影響を受ける場合があります。他のアプリやクラウドに書き出したコピーは、その保存先で別途管理してください。

8. 広告・追跡・情報販売

アプリに広告や行動追跡の SDK は使わず、個人情報を販売しません。ご自身が選んだ外部の処理・ダウンロード・共有サービスは、それぞれの方針に従います。

9. 選択とお問い合わせ

アプリで処理方法の変更、録音・記録・モデル・API キーの削除、検索・診断の無効化ができます。個人情報の開示・訂正・削除や処理については ujbj84@gmail.com にお問い合わせください。Fordy はデバイス内だけに保存された録音やキーに遠隔アクセスできません。

10. 変更のお知らせ

機能や処理方法が変わった場合、この方針と施行日を更新します。重要な外部送信の変更はアプリ内でも案内します。
