VOICE TO WORDS. CONVERSATIONS TO MEMORY.

말의 흐름을,
기록의 힘으로.

메시지는 말로 쓰고, 대화는 오래 남기세요.
Fordy Flow는 음성 키보드와 회의·인터뷰 기록을 하나로 잇는 iPhone 앱입니다.

iOS 앱 배포 준비 중
01 / WRITE

말로 쓰는 키보드

다른 앱의 입력창에서도 음성으로 문장을 만들고, 한국어 두벌식·천지인으로 직접 입력하세요.

02 / RECORD

대화를 기록으로

회의와 인터뷰를 녹음하고, 전사·화자 구분·회의록으로 다시 살펴보세요. 필요한 형식으로 내보낼 수 있습니다.

03 / CHOOSE

처리 방식도 직접

기기 안에서 처리하는 로컬 모드와 본인의 Groq API 키를 사용하는 클라우드 모드 중 선택하세요.

iPhone 앱은 iOS 18 이상, 음성 키보드 기능은 iOS 26 이상에서 지원합니다. Apple Intelligence 기능은 지원 기기와 시스템 모델 준비가 필요합니다. Groq 이용에는 별도 계정·API 키가 필요하며 해당 서비스의 요금과 사용 한도가 적용됩니다.
